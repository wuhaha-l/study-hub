功能对照：一个都没少

下面这些是现在首页上真实存在的交互，两套设计都留了位置。左侧是功能，右侧是它在两个方案里落在哪儿。

功能方案一（分组列表）方案二（磁贴）
待完成 / 过期 / 7 天内 / 完成率顶部概览卡：大数字 + 三个胶囊 + 完成率环2×2 磁贴里的两块（待完成、完成率环）
平台三卡（数量 / 绑定状态 / 失效）「平台」分组三行，右侧数量 + chevron，失效行红字顶栏下方三个胶囊，未绑定置灰
同步全部课程和任务（含转圈 / 分阶段文案）大标题右侧 ⟳ 圆按钮（转圈）顶栏 ⟳ + 下拉刷新，同款分阶段文案走顶部小 toast
主题切换 / 登录设置🌙 在标题右侧；⚙ 收进「账号与登录设置」行（iOS 习惯把设置放列表里，也给右上胶囊让位）顶栏 🌙；账号入口同样落在列表底部的账号行
今日课程（含「正在上」、地点、本周节数、无课文案）「今天 · 周二」分组，行内时间片 + 课名 + 地点，「在课表中查看」蓝字入口首屏底部课程行（下一屏置顶），点进课表
平台筛选（全部 + 3 个平台，带数量）iOS 分段控件，四段胶囊 chip 行，选中反白
学期筛选（本学期 / 全部学期 + 说明）「待办」标题右侧「新学期 ⌄」菜单chip 行首段「新学期 ⌄」
课程筛选同级「课程 ⌄」菜单chip 行第二段「课程 ⌄」
7 类分组（过期 / 今天 / 一周内 / 更晚 / 章节 / 不用做 / 已完成）+ 折叠按分组顺序下排，「已完成 / 不用做」收成两行可展开卡片流按分组排，「已完成 · 不用做」合成一张折叠条
任务行信息（平台、课程、必做/选做、往期学期、类型、进度、截止分级、已完成态）标题 + 灰色副标题（平台 · 课程 · 类型 · 进度），角标贴在标题后，右侧截止卡头一行放平台/课程/截止，标题加粗，底部一行放类型 + 进度条
长按菜单（完成 / 恢复 / 详情 / 复制链接 / 删除）iOS 上下文菜单（毛玻璃 + 取消）同款 contextMenu，从卡片浮出
新建任务（标题 / 课程 / 日期 / 时间 / 提醒 4 档 + 自定义 / 额度说明）「＋」进 sheet，同方案二样式底部 sheet，分组表单 + 双按钮
每日提醒卡（开启 / 续订）「每日提醒」行，右侧「开启」蓝字卡片 + 开关
记事本 / 专注（条数、番茄数、分钟、进行中）「工具」分组两行，副标题显示今日数据2×2 磁贴各占一格
错误提示 / 同步警告 / 云函数版本过旧列表顶部一条黄色 inline 提示行顶部毛玻璃提示条，可点开
加载骨架 / 未绑定引导 / 全空态分组列表骨架条；引导卡改成分组 + 蓝色按钮磁贴占位块；空态卡居中
页脚（上次同步 / 服务版本 / 长按提示）+ 退出登录页脚小字 + 账号分组末尾的红色「退出登录」行页脚小字 + 底部「退出登录」红字
两点说明：① 方案一保留了「大标题」这个 iOS 特征，所以顶部比现在高 40px 左右，任务会晚半屏出现；如果你更在意首屏能看几条任务，方案二更划算。② 两套都没有加底部 tab bar —— 你现在 8 个页面是靠导航跳转的，凭空加个 tab 会改信息架构，那个要单独定。
